The Problem

One-shot AI generation
produces demos, not tools.

When a user says "build me an inventory tracker," current AI generators make 70+ implicit decisions the user never agreed to.

User Intent
"Track my inventory"
Black Box
70+ silent decisions
Fields? Relationships?

AI Output
14 fields you didn't ask for

01
Assumption-heavy
AI guesses fields, relationships, workflows. User never agreed to any of them.
02
No recovery path
70% right + 30% wrong = start over. There is no middle ground.
03
Generic, not contextual
Doesn't know the user has 4,200 contacts in CRM or a custom deal stage.
04
Structural hallucination
Without Creator constraints, AI generates plausible components that don't work.
05
Users prompt poorly
"Build me a vendor onboarding app" is reasonable. It's a terrible generation prompt.
06
Patience is finite
~90 seconds of trust. Miss the window and the user leaves. Forever.

Plan

Plan Generation

AI acts as a solution architect — turning requirements into a structured, phased build plan.

  • 1
    3-4 build sprints — Foundation (forms) → Logic (workflows) → Presentation (reports/dashboards).
  • 2
    8-15 concrete tasks — each described as a user story with dependencies mapped.
  • 3
    Decision points identified — high-impact choices surfaced for user, low-impact ones auto-resolved with AI reasoning.
→ Plan ready → Plan Review
05 / 08
Plan

Plan Review

The user's "blueprint review" moment. See exactly what will be built, make decisions, refine via AI chat.

  • ●
    Task cards — visual sticky notes grouped by sprint, color-coded by type (setup / logic / views).
  • ●
    Decision log — high-impact choices need user input. Low-impact ones auto-applied but overridable.
  • ●
    AI refinement — chat to tweak any task or restructure the whole plan. Changes apply live.
◆
Gate 2: User reviews the full plan before any building begins. They choose which sprint to start. Nothing is built without explicit approval.

Build

AI builds each task. User approves every result. One sprint at a time.

Design Principles

The intentional product choices behind the flow

01

Progressive Disclosure

User starts with a single prompt. Complexity is revealed gradually through conversation, then layered into sprints, tasks, and details. Never overwhelming.

02

Human in the Loop

Three explicit gates: approve the flow, review the plan, approve every task. AI proposes, user disposes. No black box.

03

Sprint-Based Building

Work is broken into logical sprints (Foundation → Logic → Presentation). Natural review points between each. Mirrors how real projects ship.

04

Always Resumable

Close the browser, come back tomorrow. All progress is saved. The Kanban board shows every app and its current stage at a glance.

05

Continuous Iteration

The flow is a loop, not a line. After delivery, jump back to Discovery with full context: "Add purchase orders." AI knows what's already built.

06

Transparent Decisions

High-impact choices require user input. Low-impact ones show AI reasoning and can be overridden. The user sees every decision made on their behalf.
